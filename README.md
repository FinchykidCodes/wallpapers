\# Wallpapers



A collection of wallpapers I like.



\## Usage

Clone the repo or download individual images from the `wallpapers/` folder.



&#x20;   git clone https://github.com/YOUR-USERNAME/wallpapers.git



\## Structure

\- `wallpapers/nature`

\- `wallpapers/abstract`

\- `wallpapers/minimal`

\- `wallpapers/dark`
